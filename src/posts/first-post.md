# 歡迎來到我的博客

這是第一篇使用 Eleventy 建立的文章。

## 功能特點

- ✅ 支援繁體中文（香港地區）
- ✅ 整合 Cloudflare 媒體服務
- ✅ 自動部署到 GitHub Pages
- ✅ 快速且安全

## Cloudflare 圖片示例

如需插入 Cloudflare Images 的圖片,使用以下語法:

```
{% raw %}{% cfImage "your-image-id", "圖片描述", "public" %}{% endraw %}
```

## Cloudflare Stream 影片示例

如需插入 Cloudflare Stream 影片,使用以下語法:

```
{% raw %}{% cfVideo "your-video-id" %}{% endraw %}
```
